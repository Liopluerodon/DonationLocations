# DonationLocations
Community-oriented charity and donation locations for the less fortunate. Aggregates and organizes important data with emphasis on readability. Created as a part of the CityCamp hackathon!

This was created to solve the problem of information. There are plenty of resources out there, but most of them are unknown to the public. We have made it easy for users to find food pantries and others within Gainesville, and included a few locations users can use now. It is also possible for others to contribute by adding locations they know about in the csv file, which will be appropriately formatted by our program.

The website includes filters by day, and items, and works through extracting the data from a .csv file, which then gets put on the website.
